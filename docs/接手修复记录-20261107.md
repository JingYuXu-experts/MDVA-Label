# MDVA 网页版接手修复与验收记录

日期：2026-11-07。产品主体为 Vue 3 / TypeScript 网页、Python 标准库 HTTP 服务和 SQLite；原 Python 客户端仅保留源码。本记录描述本次实际交付，不把历史交接中的冻结安排当作当前要求。

## 启动体验补充修复

根据本次使用反馈，默认入口调整为 Python 启动器 `启动MDVA.pyw`，`python main.py` 和 `run.bat` 同样调用它。启动器自身仅依赖标准库及 Tk，不会在环境检查前导入科学引擎。首次查找本项目虚拟环境、登记的 conda 环境和 PATH Python，实际检查 Python 3.10+、numpy/scipy/pandas/Pillow/astropy/scikit-image/openpyxl 以及应用模块；通过后才启用「启动应用」。允许选择环境，并在窗口内按需安装运行依赖。

成功启动后才记录 `.mdva/launcher.json`，后续无设置窗口直接打开网页；未完成设置、环境损坏或启动失败会显示设置。环境与服务日志只保存在本地 `.mdva/`，不提交。首次弹窗不是恢复旧客户端，实际应用仍是网页版。

验收：启动器及 HTTP 回归 **40 项通过**。实际窗口自动选择本机 Python 3.10.20 环境，点击启动后关闭窗口并打开浏览器；用独立验收配置复测第二次启动无弹窗、复用已有服务；关闭本轮自己的服务后由启动器冷启动成功（4.53 秒，包含后台环境检查），health 身份核对通过。截图 `out/acceptance/launcher-first.png`。测试配置写在 `out/acceptance/launcher-test.json`，保留用户真实首次使用流程，未预先标记真实配置为已完成。

后续修正默认数据范围：原先首页使用最新创建的数据集，导致 90 张验收样本排在完整数据之前。现在无明确 URL 选择时优先同类只读源的最大索引集；有效的显式选择不覆盖。管理台新增当前数据集、索引总数、筛选数量、每页数量；样本集可一键切回完整源。数据库按 AR/CH/FL 核对为 5,092 / 3,831 / 4,625 张，API 返回总数 13,548、单页 120。类型检查、lint、构建通过；Chromium 验证无参数首页默认全量、样本集跳转按钮及最终 113 页显示，截图 `out/acceptance/data-full-context.jpg`。

双击仓库根目录 `run.bat`，或在已安装依赖的环境执行 `python main.py`。默认地址 `http://127.0.0.1:8765`。首次显式创建 `data` 工作区；启动时登记本机 SSAFD 目录为只读源。同端口先核对 MDVA 服务版本、工作区与输出目录，相同才复用。Windows 采用独占 socket 绑定，避免两个进程抢同一端口。其他服务冲突会提示换端口。

## 缺陷与实现

| 问题 | 本次处理 | 验证方式 |
|---|---|---|
| 默认仍启动 Tkinter | 默认网页启动，旧客户端退出默认流程 | 本机启动、服务复用及冲突回归 |
| SQLite 共享连接读写交错，出现“未知版本” | 同一 RLock 包含读取、校验、写入与结果提取；嵌套事务不提前提交 | 并发用例与全量 pytest |
| 替换标注中途失败可能丢失旧内容 | 整体事务，失败全部回滚 | 已批准标注混入的回滚用例 |
| 右半区合法框被拒绝、导出越界 | 修复角点语义、裁切多边形、面积/框重新计算、跳过原因报告 | 坐标与四格式回读 |
| JSON 字符串和嵌套参数绕过路径验证 | 递归解析/归一化，写权限与源只读权限分离 | 容器、模板、空白及正向消费测试 |
| 撤销清单正文可指向任意位置 | 所有源、目标、目录及动作先整体校验，才删除或移动 | 无部分删除/移动回归 |
| 二维 NPY、NPZ 误判时序/视频 | 通用接入对含糊载体返回中文诊断；专用导入识别整型实例掩膜 | 数组类型、形状与 NPZ 用例 |
| 真实目录无法直接导入 | 只读数据源登记、头部预检、持久化配对与 NOAA 映射 | 全量数量核对 |
| 管理台全量读取、旧请求覆盖、源缩略图空白 | 服务端分页筛选、请求代次保护、统一源别名 URI | 浏览器全量列表、缩略图、切换场景 |
| 原始掩膜与人工近似混淆 | 原始掩膜不可变；人工修改新建版本；导出来源显式区分 | 原始 RLE/栅格逐像素核对 |
| RGB 增强误把通道当空间轴 | 统一 HW/HWC 空间尺寸，翻转/裁剪与掩膜/几何一致 | RGB、掩膜与重放测试 |
| 实例编号被压成 8 位 | 掩膜按范围使用 PNG16，超范围使用 NPY；拒绝非法编号 | 大编号掩膜往返 |
| 清洗后的版本仍显示被剔除条目 | 按任务谱系解析版本成员，派生版本不修改父版本 | 90→89 与父版本保持 90 |
| YOLO 跳过多边形仍留下多余图像 | 确认标签后写图；检测可显式从多边形派生框 | 跳过统计及导出回读 |
| 重复内容、增强副本跨划分泄漏 | 内容组与源家族分组，固定种子控制排序 | 同源划分隔离 |
| 长请求断开后误认为取消 | 任务真实状态入库，停止等待只断开客户端 | 状态与失败记录测试 |
| 安装版本、静态资源、机器路径不一致 | 统一 0.1.1，打包网页，示例根目录改相对路径 | 隔离 wheel 导入及 HTTP 冒烟 |

| 类别 | 图像 | 掩膜 | 配对 | 无掩膜图像 | 无图像掩膜 |
|---|---:|---:|---:|---:|---:|
| AR | 5,092 | 4,308 | 4,308 | 784 | 0 |

| FL | 4,625 | 3,836 | 3,793 | 832 | 43 |
| 合计 | 13,548 | 11,968 | 11,914 | 1,634 | 54 |

仅索引图像/NPY 头部及 NOAA 表，不全量加载像素，也不自动清洗增强。缺失、尺寸不符、头部损坏、重复和对应表冲突写入预检报告；无图像掩膜单独列出。AR 的 `FILENAME + MASK_NUM` 关联 NOAA，保留来源和未匹配状态。像素内容异常可在按需载入时诊断，头部预检不等价于全量像素完整性扫描。

## 接口与迁移

现有 `/api` 保留。工作区通过 `ws` 参数选择，路径必须在启动时允许的根内。原始源使用 `@ssafd/相对路径`，派生产物写到工作区或 `--out`，不可写回源。

| 接口 | 用途 |
|---|---|
| GET /api/sources | 已登记只读源；源目录由启动 `--source ID=PATH` 指定 |
| POST /api/imports/preview | `source_id` 预检，返回扫描 ID、数量和异常 |
| POST /api/imports | 使用扫描 ID 执行，返回任务及数据集/版本；可抽取每类别 30 对 |
| GET /api/items | `page`、`page_size`、`state`、`modality`、`search`、`category`；返回条目、总数与状态汇总 |
| GET /api/items/uris | 处理范围需要的当前版本 URI 列表 |
| GET /api/reference | 图像配对的实例编号、像素统计及 NOAA 元数据 |
| GET /api/reference/overlay | 使用同一配对记录与显示缩放规则生成透明掩膜 |
| GET /api/reference/polygons | 轮廓近似，用于复制成人工草稿 |

精确字段以 `src/mdva/web/routes.py` 和前端 API 类型为准。schema 3 新增 `source_mount`、`sample_index`、`import_scan`，旧库打开时迁移，保留数据集与标注。数据源可以用相同 ID 在新路径重新登记。清洗与增强的原始/派生掩膜关联随版本谱系解析，预览与导出共用关联记录。

## 后续边界

本轮不含像素画笔、真实深度模型、多用户账号、远程访问或训练扩展。深度后端在算法页保留能力占位且不可执行。多边形不能无损表达原始掩膜孔洞，需精确真值时选择原始掩膜 COCO 导出。现有科学引擎与旧客户端源码保留，不据此承诺每种旧 GUI 交互已复测。

长任务仍为同步 HTTP 请求，服务端任务状态持久化；断开等待不会取消已经执行的任务。进程被直接终止的任务没有自动断点恢复。本机角色切换是工作流辅助，不是账号鉴权。后续可继续改善高密度标注交互、全量长任务队列与专项浏览器性能测试；这些限制不以虚构状态或演示数据掩盖。

`out` 中验收证据、数据库与原始数据只作本地交付，不加入源码提交。使用与安装说明见根目录 README。
