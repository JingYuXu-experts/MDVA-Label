# 三维磁层与太阳活动升级记录

日期：2026-11-11。本记录取代此前“只有一阶近地内源场”的运行说明。当前为模型驱动首版，仍在开发。

## 直接使用

运行 `python launcher.py`，访问 <http://127.0.0.1:8765/monitor>，进入三维全屏。

1. **全局磁层**：查看数值追踪的磁力线、磁尾和独立磁层顶估计。地球近景可检查近地部分；支持旋转、缩放、悬停/点击解释。
2. **磁层参数**：默认读取有时间的 L1 与 Dst 快照；切换手动实验后，可改变动压、Dst、IMF By/Bz 并重新计算。手动结果一直标记为实验。约30秒的计算在独立进程完成，结果与失败均落库，可在任务记录核对。
3. **太阳近景**：将 AIA 观测投影到可见半球，背面使用未知网格；日缘外发射保留在原观测平面。太阳近景隐藏轨道线和太阳风示踪，以便检查活动结构。
4. **太阳活动观测**：AIA 171/193/304、HMI、LASCO C2/C3，选择 UTC 时间，放大、拖动、上一/下一帧、时间轴播放。固定离线时序可保留缓存。
5. **2012日珥喷发案例**：读取 2012-08-31 20:15—21:15 UTC 的13帧 AIA 304。NASA记录了当天20:36 UTC附近的暗条喷发；这里播放实际影像，不生成喷发形状。
6. **磁层 MHD 模型**：查看 NOAA Geospace/SWMF 的速度、密度、压力切片，切换批次、播放或拖动。未来有效时刻明确标为模型未来；播放不跨批次。
7. 原来的 **官方二维模型** 继续提供 WSA–ENLIL，不被三维入口替换。

## 磁场和参数依据

| 项目 | 当前实现 | 限制 |
|---|---|---|
| 内源场 | IGRF-14 系数；Geopack 的完整内部场计算 | 已打包系数时间1900—2030年，拒绝超窗外推 |
| 外源场 | Tsyganenko T96；环电流、尾电流、磁层顶电流等经验分量 | 瞬时半经验估计，不是MHD时间推进；不是保证精确的实测场 |
| 磁力线 | 沿总场 `B/|B|` 双向数值积分；60个足点种子，RK2、自适应空间步长 | 绘制域 GSM X −50～20，Y/Z ±30 Rₑ；出界不表示磁场终止；有限场线是采样 |
| 磁层顶 | Shue et al. 1998 的三维旋转对称经验表面 | 独立于T96，不是T96等值面，可能与T96场线不完全一致；不显示为精确保护范围 |
| 观测驱动 | NOAA RTSW质子速度/密度、GSM By/Bz，NOAA分发的Kyoto Dst | 风/磁场最大时差5分钟、最长年龄15分钟；Dst最长6小时；不使用缺测默认值 |
| 动压 | 质子 `m_p n_p v²`，输出nPa | 无α粒子资料，因此没有估计其贡献；自动值明确标为仅质子 |
| 参数时间 | 参数逐项保留原观测时间与来源 | L1没有传播到磁层顶的时移；Dst是小时指数；不是此刻磁层实测 |
| 手动实验 | 动压0.1—50nPa，Dst −300～50nT，By/Bz ±50nT | 允许范围是交互边界，不代表整个范围都在模型标定域；超常见中等扰动条件明确警告 |

Geopack 1.0.13 的MIT许可数学实现与IGRF-14官方系数已随应用打包。修改仅限包内相对导入、删除导入时HTTP下载和控制台输出；数学例程保留。上游来源、原始代码SHA256、系数SHA256见 `src/mdva/physics/geopack/PROVENANCE.json`。运行模型不需要联网或额外安装geopack。

数值追踪放在独立Python进程，避免共享Fortran风格全局变量和HTTP线程GIL竞争。数据库仅在读写结果时短暂加锁。输出按模型修订、参数和来源快照缓存；进程失败/重启有状态，可重试。

## 太阳活动与风向

Helioviewer先查询最近影像的ID和实际观测时间，再按不可变ID下载1536像素彩色浏览图。请求与实际观测相差超过30分钟时明确报缺测；不使用最新图填补旧时刻。保留伪彩性质、元数据、来源和请求时差。该浏览图不是科学定量测量所需的原始FITS。

AIA 304展示日面暗条、日缘日珥等结构；171、193提供不同温度响应的日冕信息。某张图像明亮不能单独证明耀斑；LASCO遮挡盘也不应被解释为太阳消失。单视角不能恢复日珥深度、背面活动或唯一三维结构。

金色径向示踪显示定常向外运动方向，参考速度取L1；局部GSM箭头指向地球迎日面。示踪数量不是实际粒子数量/密度；进入近地空间后停止这种简单示踪，没有将它画成未经计算的磁鞘绕流。AIA形态、磁层快照和天文加速时钟独立标时，未建立某次喷发和地球响应的因果关联。

真实太阳风—磁层相互作用的时序由NOAA业务Geospace模型切片展示。它结合BATS-R-US、RIM、RCM；当前公开接入的是二维切片，不能据此宣称已取得完整三维数值网格。

## 接口和原数据保护

保留 `/api/sw`，增加 `solar/image`、`magnetosphere/model`（POST创建、GET读取任务）、`magnetosphere/frames`。浏览器不能提交任意远程网址或本地路径。所有下载仍经过采集模块的HTTPS白名单与响应上限。太阳影像、模型、来源与任务使用独立监测库及缓存，不修改三套本地原始数据和人工标注。

## 验证记录

- T96独立外源分量对照上游公开Fortran算例，误差小于0.002nT；不把整套模型称为真实世界精确解。
- 验证Shue参数变化的压缩方向、GSM右手正交基、磁力线空间步长减半的闭合线顶点收敛、场强有限、积分域、离线计算。
- 验证负By/Bz/Dst保留、填充值排除、缺参数/过期/时间不匹配拒绝、不可变影像ID、缓存请求时差、失败落库与重试。
- 全量pytest：714通过、18跳过（146.14秒）；前端类型检查、lint、构建均通过，结果见 `out/acceptance/physical-upgrade-*`。18个旧GUI用例需要 `MDVA_GUI_TESTS=1`，当前保留跳过。
- Chromium实测真实T96输出、手动参数、风向示踪、AIA投影、13帧历史喷发、MHD批次、二维ENLIL保留、切页销毁WebGL、390px手机布局。脚本 `frontend/space-products-check.mjs`；报告 `out/acceptance/physical-products-browser.json`，截图同目录，录像位于 `physical-products-video`。
- 独立计算进程运行时一次摘要请求约14ms，仅为该次测量，尚不是P95验收结果。软件WebGL用于功能检查；另以Chromium默认ANGLE确认使用RTX 5060 / Direct3D11，在1600×1000全屏T96场景采样约50FPS，记录为 `physical-hardware-browser.json`；这是单次共享负载测量，非性能保证。构建仍有大于500kB分块提示，不影响成功构建。
- 全量检查首次在并行渲染/计算负载下暴露旧提示传播用例的计时门槛：匹配结果正确，2张小图的加速比0.745低于0.8。失败证据保留 `physical-upgrade-pytest-under-load.txt`。已将该功能用例的速度断言改为有限且正值，保留坐标、数量和线程数断言；专门的大批量性能用例仍保留。随后完整重跑通过。
- 修正构建HTML的重复回车；默认天文时钟改为1×实时，教学加速由用户显式选择。近期影像自动每15分钟检查更新；手动选择的历史影像不被自动刷新覆盖。13帧固定验收案例已单独固定缓存。
