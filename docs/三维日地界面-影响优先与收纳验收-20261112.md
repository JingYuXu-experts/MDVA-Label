# 三维日地界面：影响信息优先与收纳验收

日期：2026-11-12。本次仅调整网页的信息层级与交互，不修改物理计算、信源关联或数值训练代码。

## 当前入口

默认简洁浏览。三维画面上方显示三项：可能影响的领域、所选喷发是否波及地球、预计到达（北京时间）。领域标为科普说明，不能当作本事件的预警；NOAA 等级说明链接直接可见。事件可从顶部选择，无需翻到底部。

有明确地球到达估计时显示时间；预计时刻已经过去时显示“待观测确认”。资料不足显示“尚不能确定 / 暂无估计”，不解释成没有影响，也不借用其他探测器的到达时间。

## 默认收起与可恢复内容

- 顶部“事件依据与不确定性”“上游实测与图像解读”默认折叠。
- 页面底部 CME 事件分析、事件关联与地球到达核验默认折叠。
- 四步教学从“图解说明”打开；再次点击收起。简洁场景默认显示背景太阳风方向，未据此宣称存在风暴。
- “显示设置”单独控制影响摘要、四步图解、观测时间与来源、专业控制面板。收起摘要后有明确的恢复按钮，选择的事件保留。
- 全屏摘要置于画布上方，展开依据也不盖住天体。手机摘要采用两行布局，三项主要信息与来源链接在顶部可见。
- 太阳活动观测、磁层变化回放和官方二维模型保留。进入前两者暂不显示事件摘要，返回三维场景恢复。
