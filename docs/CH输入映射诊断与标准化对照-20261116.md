# CH输入映射诊断与标准化对照

本轮没有训练模型，也没有替换网页候选。完成了训练与验证输入的全量灰度统计，以及同一权重下的原输入／标准化输入对照。结果表明该处理能减少部分漏检，但增加多标，未通过预先固定的Precision保持门槛。

## 输入事实

训练为2010—2017年的2410张CH图，验证为2019—2020年的526张。只从训练图像拟合亮度锚点，没有用掩膜拟合，也没有打开校准或测试图像。

| 项目 | 训练 | 验证 |
|---|---:|---:|
| 全部图像 | 2410 | 526 |
| 可可靠拟合可见日面 | 1975 | 458 |
| 拟合不足，保留未测量状态 | 435 | 68 |
| 日面半径0.8以内的灰度中位数 | 66 | 81 |

这里是8位显示图的灰度，不是太阳辐射强度。无法可靠拟合的图像没有从完整验证评价中删除；处理时回退到原输入。

本地原团队`datas of importance/Code/AIA_processing.py`在`draw_aia`中调用每幅图的99.9百分位作为上界，再做平方根映射、居中与缩放。它说明提供的代码具有逐图显示映射，但尚未逐文件证明所有下载JPG都由该确切版本产生。灰度统计差异也不能单独证明处理出错，太阳状态、相对对比度和生成流程都可能参与。

CNN193原论文的基础输入处理是缩放并将0—255映射到0—1。本轮额外的亮度对照是本项目的诊断假设，不是原论文复现，也不是物理校准。[原论文第2.3节](https://arxiv.org/html/1809.05748)

## 已固定的对照

模型始终为CH-C2-s2026，阈值始终0.5。比较完整526张验证图，原图512×512。标准化用训练锚点66除以当前图像日面内部灰度中位数，只对可见日面像素做乘法与0—255裁切，外部保持不变；不能可靠拟合或倍率超出预定0.5—2范围时原样输入。

处理不读参考标签或预测结果。两次前向完成后才读取参考进行评分。原输入526张的TP、FP、FN逐项与历史验证一致，排除了本轮新评价口径改变造成的表面提升。

预先固定门槛为半覆盖比例至少增加3个百分点、完全未覆盖参考区域数至少减少5%、Dice最多下降1个百分点、Precision最多下降3个百分点。没有扫描多个变换参数或更换阈值。

## 完整结果

| 指标 | 原输入 | 标准化输入 |
|---|---:|---:|
| 平均Dice | 79.07% | 79.47% |
| 像素Precision | 86.17% | 82.40% |
| 像素Recall | 74.87% | 78.67% |
| 至少一半像素被覆盖的参考区域 | 1306/1924，67.88% | 1377/1924，71.57% |
| 完全未覆盖的参考区域 | 347 | 301 |
| 框IoU≥0.5区域召回 | 59.10% | 61.12% |
| 完全不与参考重合的预测连通区域 | 347 | 544 |

覆盖率增加3.69个百分点，完全漏掉的参考区域减少46个，但像素Precision下降3.78个百分点，超过3个百分点的预定上限。最后一行的额外预测连通区域也明显增加，不能只展示Dice上升0.40个百分点就宣布成功。连通区域并不等于独立物理实例。

2019年Dice从77.61%到78.46%，2020年从81.66%到81.25%，年份间效果不同。完整验证包含68张原样回退图，未删除困难样本。

配对UTC 27日时间块bootstrap 2000次、固定种子2026，标准化减原输入的Dice差值95%区间约为[0.006,0.802]个百分点；半覆盖比例差值区间约[2.17,5.24]个百分点。这是反复使用的开发验证集、单个固定模型的探索性比较，不是独立泛化证据，也没有据此改动已经打开的原测试成绩。

## 决定与解释

决定为不部署、不扩展这一固定输入变换。没有修改原图、参考标签、模型权重或现有模型包。不能通过临时放宽Precision门槛把结果包装成通过。

证据支持输入显示域对模型有影响；简单整体变暗使网络更容易产生前景，也增加了不受参考支持的区域。它没有证明输入变换能区分冕洞与其他暗结构，更没有证明原数据标错。若要研究训练期的归一化或新观测通道，需新的明确假设和独立协议，不自动延长本次对照。

下一步先核验输入图生成映射与多通道时间、几何对应关系，明确新增信息是否能区别不同暗结构；同时继续预测物理特征来源和实时可获得性核验。不要基于本次结果重新打开原测试集调参，也不要恢复已完成的旧队列。
