## 守护措施

- 单独后台守护进程监看现有监督器、队列和 GPU 锁，不启动重叠训练。
- Windows 训练守护存续期间申请防自动睡眠，屏幕可正常熄灭；不更改系统永久电源计划。手动关机、手动睡眠或断电仍会中断计算。
- 进程意外退出、临时内存/显存不足等已识别故障，在确认原任务退出、资源恢复、冻结身份和检查点完整后，按原配置接续。
- 每项最多自动恢复2次，总计最多6次，至少间隔60秒；等待资源超过30分钟会留证停止。恢复计数持久保存，不通过重启守护清零。
- 恢复前保存原失败状态、队列状态、检查点核验结果，失败不会被记为完成。
- 非有限数值、数据损坏、身份不符、未知异常不盲目重试；写入故障日志，保留完整轮次检查点，等待进一步定位。不会偷偷改精度、分辨率、种子、数据划分或解除测试冻结。
- 不强杀仍持有 GPU 锁的训练。上述自动恢复不等同于对所有未知软件/硬件故障的自动修复，也不承诺活进程永久卡死时可以安全接续。
- 用户暂停具有最高优先级；守护绝不自行删除 PAUSE 标记，退出后释放防睡眠请求。

## 手动接续命令

先激活 Conda mdva311；以下训练与守护命令各自是持续运行命令，在不同终端执行或由助手启动隐藏后台进程：

```bat
conda activate mdva311
python -m mdva.training unpause
python -m mdva.training continue
```

另一终端（可在队列运行后启动）：

```bat
conda activate mdva311
python -m mdva.training.watchdog
```

暂停命令：

```bat
python -m mdva.training pause
```
