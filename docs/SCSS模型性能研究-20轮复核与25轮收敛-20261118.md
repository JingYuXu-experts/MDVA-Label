# SCSS：20轮复核与有界收敛检查

北京时间2026-11-18。当前目标仍是可靠的真实图像识别、自动标注以及适配观测支持的事件预测，尚未完成。以下是CH识别支线的开发验证结果，不是新的最终测试成绩。

## 20轮完成了什么

第二阶段从8轮恢复到累计20轮，按预算正常退出，没有异常。最佳为第13轮；后7轮未刷新。最佳与第20轮检查点分别完成526张完整验证复算，与保存的Dice均完全一致。阈值固定0.5，原始参考只在推理后参与评分。

|---|---:|---:|---:|---:|
| Dice | 79.0713% | 80.7805% | 80.5677% | 80.2116% |
| IoU | 66.0282% | 68.2874% | 68.0420% | 67.5710% |
| Precision | 86.1746% | 84.6774% | 86.6025% | 86.4088% |

| 完全未覆盖的参考连通区域 | 347 | 308 | 351 | 354 |

| 完全不与参考重合的预测区域 | 347 | 215 | 143 | 198 |

最佳模型Dice比旧候选高1.7092个百分点；Precision低1.4972个百分点，Recall高3.9005个百分点。对比首8轮最佳，Dice只提高0.4067个百分点，但额外预测区域560降到215、边界F1从29.21%升至33.49%，精度—召回取舍发生变化。不能只用Dice大小概括这一变化。

最佳模型的2019年Dice为79.9103%，原模型77.6051%；2020年为82.3193%，原模型81.6642%。按UTC27日时间块、2000次配对bootstrap，Dice差值95%区间为约[1.21,2.26]个百分点。这是重复使用开发验证集、一个随机种子、不同整体配置的探索性结果，不是独立泛化证明或单因素架构贡献。

原实用门槛仍保持：Dice≥82.0713%、Precision≥83.1746%、参考区域至少半覆盖比例≥70.8794%。最佳、最后与集成都未全部通过。没有独立无目标图像队列，不能报告其图像级误报率；连通区域不等于真实物理实例或NOAA身份，未获参考支持也不能自动认定参考漏标。

等权集成在评价前固定为0.5×旧概率+0.5×新概率，阈值仍为0.5；只使用验证缓存，无优化器、无权重或阈值搜索。结果低于SCSS单模型，增加推理成本，本轮不扩展集成权重搜索。

## 真实推理成本

相同的首张训练图、512网格、batch1、两模型均FP32前向、TF32关闭，每模型预热10次，分别100次纯推理与100次读图到概率输出测量。

| 项目 | 原CNN193候选 | SCSS-GN |
|---|---:|---:|
| 参数量 | 4,365,433 | 7,851,969 |
| 纯推理P50 | 25.39 ms | 43.50 ms |
| 纯推理P95 | 28.16 ms | 45.98 ms |
| 含缓存读图与预处理的P95 | 32.66 ms | 49.51 ms |
| 推理分配显存峰值 | 0.1701 GiB | 0.2723 GiB |

SCSS纯推理P95是旧模型的1.63倍，不能宣传为更轻更快。第一个速度试测与CPU集成评价重叠，因此作为带竞争试测保留在`scss-speed-20-01`，第二次在其他评价进程退出后测量，作为主资源对照保留在`scss-speed-20-02`；没有从多次运行中挑最快结果。上述不是网页完整交互耗时或并发服务性能。

## 第三阶段：只追加5轮

20轮完整复核后，决定在不改变模型、输入、损失、阈值、Adam、原学习率调度及随机状态恢复的前提下，追加最多5轮，到累计25轮。原自然早停规则保留；不是批准跑满40轮。

理由：最佳相对首8轮有小幅改善，额外区域与边界表现改善；同时原调度在第18轮才把学习率降低到0.00025，20轮时只观察了该学习率两轮。追加有限预算核验这一步的收敛，有别于盲目扩宽模型或另开配置矩阵。

阶段登记：`out/recognition-improvement-20261117/scss-full-01/refinement-25.json`。它固定了20轮最佳/最后、集成与资源报告哈希、20轮起点检查点与轨迹、接续代码身份。原`active-stage.json`及20轮评价协议保留，不改写。

25轮停止后评价best和last，不自动追加预算。要支持进一步开发，要求最佳Dice相对20轮再提高至少0.5个百分点，同时满足原Precision和区域覆盖下限，或完整通过原实用门槛；否则关闭该配置的进一步加轮支线。此为工程研究取舍门槛，不是业务达标或统计显著性定义。

暂停：写入当前`scss-full-01/run/PAUSE`，等待当轮完整保存和进程退出。用户明确恢复并保留、撤销暂停标记后，使用：

```bat
python -m mdva.training.scss_resume --study out/recognition-improvement-20261117/scss-full-01 --stage refinement25
```

该命令按检查点计算到25轮的剩余预算，例如23轮仅补2轮。旧的默认接续入口仍只面向20轮阶段，不会自行扩展。训练睡眠保护只跟随已核验PID和创建时间，不自动重启任务。

25轮后命令：

```bat
python -m mdva.training.scss_review25 --study out/recognition-improvement-20261117/scss-full-01 --output out/recognition-improvement-20261117/scss-review-25-best --checkpoint best
python -m mdva.training.scss_review25 --study out/recognition-improvement-20261117/scss-full-01 --output out/recognition-improvement-20261117/scss-review-25-last --checkpoint last
```

新入口要求25轮完整保存、训练停止、GPU互斥及身份一致；不读取测试或校准图像。

## 真实案例和归档修正

最佳与最后模型各有12张对照案例，分别位于`scss-review-20-best/case-viewer/打开看真实效果.html`和`scss-review-20-last/case-viewer/打开看真实效果.html`。固定年份分层案例与事后改善/退步案例分开，有原图、参考、旧预测、新预测、错分图。已在Chromium核验24张图加载、点击放大及训练页25轮预算展示，页面错误为空。

归档检查发现：旧8轮报告保存了完整逐图分数和预测缓存、原检查点哈希，但没有独立保存当时最佳权重（第1轮），随后训练最佳文件被第13轮替换。旧预测证据仍在，但旧权重的再次推理复现尚未恢复；不能声称哈希记录等于权重归档完整。后续可用原配置、种子与代码独立重放首轮，只有核验后才能称为恢复。

已修正新评价流程：持GPU锁时先独立归档`checkpoint.pt`，复制前后及回读检查SHA；不覆盖冲突文件，拒绝源文件变化。20轮best/last均有独立权重归档。继续训练前完整保存`scss-full-01/stage20-snapshot`，包含协议、阶段、身份、20轮历史、状态、best/last及哈希清单，供20轮语境重放。

## 后续输入研究的真实证据

固定16张训练图对应的171/193/211官方AIA synoptic FITS共48份已核验。193/211时间差约7秒，171/193约4.23—4.51秒，质量字段0、Level1.5、网格字段一致，原始HDU校验通过。193按团队提供固定公式重建，与本地JPG固定核心区域相关系数最低0.99635、中位0.99788。25种±1像素位移诊断中，16张均以零位移时核心误差最小，未移动任何原图或标签。

这仍不是完整物理配准验收。本地外圈白背景步骤未解释；历史definitive产品有延迟，不能当作当时实时可得预测输入。当前训练输入不变，`training_allowed=false`。
