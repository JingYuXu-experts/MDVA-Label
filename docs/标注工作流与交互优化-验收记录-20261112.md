# 标注工作流与交互优化：使用说明与验收记录

日期：2026-11-12。范围为现有网页的素材浏览、人工标注、清洗、增强和导出交互。算法管理与太阳识别模型本轮未开发。当前仍为开发版。

## 使用方法

通过 `python launcher.py` 启动，在管理台打开需要的数据集，再进入标注页。各工作页顶部新增统一流程入口，显示当前数据集和版本，可以依次进入“素材管理 → 人工标注 → 质量清洗 → 图像增强 → 结果导出”。

### 1. 浏览并标注图片

- 左侧改为素材缩略图列表，展示文件名、序号、标注状态和标注数量。搜索支持文件名或路径，状态筛选支持未标注、草稿/待修订、待审核和已通过。
- 展开“列表显示设置”可调整缩略图大小与列表宽度，设置保存在当前浏览器。缩略图按可见区域加载，支持失败重试。
- `#001` 等数字是**当前筛选顺序中的序号**，不是永久图片 ID。完整路径可通过鼠标悬停查看。底部支持翻页与跳页，顶部支持上一张、下一张、保存并下一张，并能跨越分页边界。
- 图像工具保留选择、矩形、多边形和点。多边形逐点绘制，双击或 Enter 闭合。可以直接“添加类别”，已有类别与颜色保留；新建数据集默认提供 AR、CH、FL。
- 使用保存、提交审核、通过和退回修订完成状态流转。已通过的标注保持只读，先点“修订”才能修改；同一张图片上可以继续添加新草稿，已通过标注的 ID 和状态不会被替换。
- 保存失败会持续显示原因，画面中的修改仍保留，可以重试。保存请求期间继续绘制的内容仍标记为未保存；切换图片或页面时会提醒处理未保存内容。
- 原始掩膜仍是只读参考。人工标注与原始参考分开保存，类别 FL 指日面暗条，不是耀斑。

### 2. 检查并整理图片

清洗页现在按三个步骤组织：

1. 选择处理范围：当前页、已选图片或整个版本。界面显示本次张数。
2. 选择“重复图片检查”或“模糊图片检查”，点击“检查这批图片”。先看实际检查数量、保留数量、候选图片与原因。
3. 确认后“生成清洗版本”，再继续标注、增强或导出。执行记录和回退收在折叠区。

检查过程不修改原文件。输出版本只包含本次选择范围中保留的图片，原版本继续保留；“当前页”不会悄悄变成全量处理。更改范围、阈值或检查项目后，旧结果立即失效，必须重新检查才能生成版本。

常用检查默认显示，阈值与图像方向/裁切放在高级区。重复检查采用保守默认值；太阳相邻时刻可能高度相似，候选结果需要人工核对。生成前会明确列出保留与排除数量。方向或裁切处理写入独立派生文件。

### 3. 生成航空航天图像增强副本

网页只显示两套太阳图像配方：轻度光度变化、训练副本。医学影像、通用计算机视觉和纯时序配方已从当前网页选择入口移除。旧配方解析代码保留，以免已有记录不能回读。

默认配方使用轻度亮度、对比度和噪声变化，保留图像方向与几何位置。每张生成几份副本可以直接设置；随机编号、数量上限与算子自定义收在高级区。它们是可调整的训练数据配方，不是经过太阳模型精度实验确认的最优参数。

点击“预览这一张的效果”，会实际计算原图/增强图对照，不再显示占位说明。预览与执行共用计划、随机参数和写出图像的编码规则；预览本身不产生文件或版本。参数、范围或样例变化时，旧预览失效。预览展示选中样例的一份副本，其余副本可能使用不同随机参数。

确认后生成独立增强版本，记录来源、实际参数和随机编号，保留既有重放能力。增强副本是训练材料，不能当作新观测；划分训练、验证和测试时仍需按原始来源分组。

### 4. 导出与回读

导出页新增当前版本图片总量、未标注数量和范围说明。无标注图片不代表已经确认“没有目标”；“附带无标注图片”明确作为可选项。继续使用已有 COCO、YOLO 等导出和回读校验，原始掩膜、人工标注与审核状态按实际选项处理。

## 缺陷修复台账

| 问题 | 修复与核验 |
|---|---|
| 左侧只有图标，无法认图、定位和调整大小 | 缩略图、文件名、筛选序号、状态、尺寸偏好、分页跳转和跨页切图 |
| 初次进入标注页偶发空白 | 合并互相竞争的初始化请求，增加上下文和响应代次检查 |
| 提交/审核后再次打开相同图片一直显示加载，无法绘制 | 已加载的同 URL 图片直接确认就绪，不等待不会再次发生的加载事件 |
| 保存期间继续绘制，新内容被误认为已保存 | 按请求提交时的快照比较，保留后续编辑及其未保存状态 |
| 保存失败后缺少持续反馈 | 保留修改并显示错误，支持重新保存 |
| 保存后当前页被重置，切换受旧请求影响 | 按当前分页刷新统计，旧上下文请求不覆盖当前内容 |
| 未保存离开时导航回调被重复调用 | 保留导航回调，确认保存、放弃或继续编辑后只完成一次 |
| 默认管理员无法提交审核 | 补齐管理员提交与修订状态流转，实际验证提交—通过—修订 |
| 含已通过标注的图片不能继续保存新草稿 | 原事务中逐项核对已通过内容并保留 ID；遗漏或偷偷修改已通过内容时整次写入拒绝 |
| 清洗参数复杂，旧预览仍可用于执行 | 常用检查卡片、手动检查、实际候选、确认窗口；参数/范围变化立即使预览失效 |
| 增强配方与当前产品无关，预览未计算效果 | 网页只展示太阳配方，增加实际增强预览接口和前后对照 |
| 按钮提示替代了可访问名称 | 保留可见按钮文字作为名称，快捷键提示继续由 title 展示 |
| 全量回归发现机构预报修订在同一时钟刻度内排序不稳定 | 修订记录以写入顺序处理时间并列，修订 ID 独立生成；固定时钟覆盖 A/B/A 修订 |
