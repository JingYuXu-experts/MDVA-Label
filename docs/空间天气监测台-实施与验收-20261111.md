# 空间天气监测台：实施、缺陷与验收记录

日期：2026-11-11（北京时间）。这是首个真实监测版本的交付记录，不代表原计划所有研究与连续运行目标均已完成。

## 启动与使用

运行 `python launcher.py`，沿用首次环境设置及记忆配置，默认进入 http://127.0.0.1:8765/monitor 。启动器开启登记信源采集，不上传本地数据集。

命令行：`python main.py serve --data data --out out --monitor-online --open`。不带联网参数、也未设置 `MDVA_MONITOR_ONLINE=1` 时，仅读取缓存。完整本地三套数据源由启动器登记。

监测大屏不要求选择数据集或标注角色。顶部可返回原太阳科学工作台和数据标注后台。

## 已实现

- 独立监测库 `.mdva/space_weather.sqlite`；公开下载缓存 `out/space_weather/`，不改变原始数据目录。
- 15 个信源项：SDO HMI/AIA193/AIA304、KSO Hα缩略观测、GOES X射线与质子通量、L1速度密度与磁场、Kp观测与预报、NOAA通报及三天预报、ENLIL清单、DONKI CME与传播研究模拟。
- 数值与通报每分钟检查；模型清单、机构预报及事件每5分钟；太阳影像每15分钟。失败退避，条件请求、压缩、去重、原始响应缓存和健康记录。
- 原始观测、机构预报、研究模拟分别展示。每项保留来源与时间；SDO无法可靠取得结构化观测时间时保留原图图注，明确只显示获取时间。
- 数值质量筛选、单位、缺测断线、峰值保留降采样、UTC/北京时间切换、独立信源错误和重试。
- 三天预报解析日期、Kp及R/S概率；保留机构原文。通报解析显式有效期、取消、过期与未知状态，支持通信相关筛选。
- ENLIL逐帧、播放/暂停、倍速、拖动、全屏、运行批次选择及同有效时刻对照。源帧整体缓存，可固定批次避免清理。
- 当前批次 `enlil_com2_58608`，169帧已缓存并固定。它是官方背景风产品，不能据此自行认定CME或生成到达时间。
- 事件检索、来源提供的CMEID关联和地球到达估计；预计时刻已过标记为等待观测确认，不自动宣告到达。
- 历史查询按系统实际获取时间选择留存版本，不能把事后获取的数据冒充当时已知信息。
- 缓存普通文件默认7天，规范化记录12个月；固定传播批次保留。清理仅针对本模块登记目录并先验证路径。
- 桌面密集布局、手机纵向布局、离线打包图表与地图。字体使用系统字体。
- `/api/sw` 下提供 summary、sources、observations、series、alerts、forecasts、events、propagation/runs、propagation/frames、assets、sync、jobs、pin；资源只接受内部ID。

## 本地数据整理

三套数据源完成跨产品索引：共93,366个文件，其中59,876张图像、23,566条耀斑事件，日期未识别图像0张。文件数包含不同产品的副本，不能作为独立训练样本数。

结构标注数据集仍为13,548张，验收样本仍为90张；两者人工标注条数分别保持4和2。没有修改原始图像、掩膜或人工标注。

修复：

| 缺陷 | 原行为 | 当前处理 |
|---|---|---|
| 耀斑表含 `//` 时间 | 整次索引失败，目录仍为0 | 保留事件，缺失字段留空；报告15个缺失/非法时间字段 |
| HSOS短文件名日期 | 824张图像日期无法解析 | 支持HrHa的YYMMDD及小时分钟写法，现为0张未识别 |
| TAI与UTC混用 | 直接把文件名日期视作UTC | 明确转换TAI并保留原标准说明 |
| MDI被统一称HMI | 仪器信息错误 | 根据文件名识别MDI，保留来源差异 |
| 异步时间轴滑块 | 清单载入后DOM滑块可能仍在0 | 显式绑定数值，浏览器逐帧检查通过 |
| pytest扫描验收备份 | 同名test_store收集冲突 | 限定tests目录，不执行out中的旧版本副本 |
| 旧离线静态门禁 | 禁止新需求所需的全部HTTP客户端 | 仅豁免公开采集模块，原数据处理仍通过离线动态门禁 |

## 验收证据

- 全量pytest：702通过、18跳过；18项均为需设置 `MDVA_GUI_TESTS=1` 才会弹窗运行的旧桌面GUI测试。日志：`out/acceptance/monitor-pytest-20261111.txt`。
- 前端typecheck、lint、build通过；构建仍提示监测分块较大，首次优化已采用按需注册ECharts组件，后续可进一步拆包。
- Chromium：无JavaScript错误，逐帧与连续播放、事件选择、手机无横向溢出、断开浏览器网络后保留已显示画面。报告：`monitor-browser-20261111.json`。
- 缓存首屏约1秒；本机20次查询抽样P95：summary约11ms、速度序列约15ms、运行批次约8ms。不是远程网络或大规模用户负载结论。
- 实际截图：`monitor-desktop-20261111.png`、`monitor-mobile-20261111.png`；真实页面5秒录屏：`monitor-5s-20261111.mp4`。这些是运行产物，不是AI生成效果图。
- 重启后仍能读取缓存与传播批次；169帧均有本地缓存。源健康首轮15项获取成功，单次成功不构成长期可用率保证。
- 基线备份：`out/before-space-weather.patch`、`out/backups/space-weather-start-20261111/`中的SQLite备份及原有未跟踪代码归档。

## 未完成与后续验收

1. **P4太阳模型尚未完成。** 当前mdva环境未安装Torch；作者代码已定位，两个本地作者仓库没有模型权重。审计结果见 `monitor-model-audit-20261111.json`。没有训练、没有太阳识别精度或24小时耀斑预测结果；界面明确未就绪。
2. **七天连续运行尚未完成。** 采集器已开始持续运行并记录health_sample，需维持本机服务并在满7天后核查成功率、间断、增长和重启恢复。不能用本次短时联调替代。
3. KSO当前只能保证取得可访问的缩略产品，最新观测可跨日；未作为暗条模型输入，也没有虚构实时Hα。
4. 首次运行只能回放自平台开始留存后的版本；官方源以前的完整历史、事后补录目录和修订比较样本仍需积累。
5. 传播比较入口已实现，但当前仅留存一个NOAA批次；真实跨批次比较随新运行积累，尚无长期定量误差评估。
6. 到达确认当前仅展示源估计与待确认状态，未实现独立冲击识别和自动观测核验，不输出具体通信链路故障概率。
7. 长期运维、代表用户任务测试和毕业论文完整实验仍待完成。当前不进行公网部署、GitHub推送或原始数据分发。

## 模型阶段的固定下一步

先审计标签时间窗口、NOAA映射及同源副本，生成按时间和活动区隔离的训练/验证/测试清单；核验SPNet原条件、CNN193和DeepFilament作者实现及许可、输入和可运行性，再锁定复现协议。模型卡必须记录代码提交、权重校验、预处理、数据划分和失败情况。

AR使用适配磁图，CH使用适配AIA193，FL使用适配Hα。24小时M级及以上预测独立建模评估，不把机构概率充当自研结果，也不把全日面文献实验直接称为活动区级复现。模型训练和业务启用需要独立验收。
