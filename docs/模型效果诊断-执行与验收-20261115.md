## 已有证据支持什么

- 历史Dice全部精确复算一致，未发现尺寸/数值/冻结文件指纹不一致；这不证明语义配对、方向和人工标注均正确。
- FL原始训练/验证图均512×512，当前训练没有额外从高分辨率缩到512；不能排除数据制作时的细节损失。
- 标准U-Net三种子平均验证Dice50.07%，完整Flat配方47.34%，C16配置48.04%，C64配置46.53%。现有Flat配置均未通过预设工程筛选门槛，暂缓继续扩展结构/宽度矩阵。
- 标准U-Net在BBSO验证图约55.49%、HSOS约41.84%、KSO约54.64%（分别91、71、20张）。台站差异明确，但台站、年份、质量和标注风格混杂，不能单独确定因果。
- 完整Flat配方的固定网格阈值观察增益不足1个百分点；仅调阈值不能把当前结果变为高质量识别。阈值始终不自动改成探索峰值。
- 参数量：标准U-Net 7,759,521；Flat C32 258,081；Flat C16 64,785。小参数量没有在本机带来更快的推理；具体P95与显存以报告为准。
- AR掩膜从1024降至512再以最近邻恢复，验证集平均Dice96.63%、最小89.84%；这是掩膜保真诊断，不是模型分数或1024输入实验，也不是理论性能上限。
- 对20个严重错误案例做±8像素小位移敏感性探针，只有1个增益达到5个百分点。它只提示局部错位/边界复核，未移动标注、未证明配准错误。

## CLI、存储与接口

在项目根目录执行：

```bat
conda activate mdva311
python -m mdva.training pause
python -m mdva.training.diagnose --experiment out/training-20261112-v2 --output out/model-diagnostics/20261115-03
```

完成后的报告不必重跑。意外中断可用同一命令从逐图缓存接续；代码、数据清单或权重身份变化必须新建报告版本。缓存复核会重新检查原始文件指纹、概率校验值与PNG完整性，损坏产物重新生成；不会用缓存掩盖原始文件改变。

只读接口：

- GET `/api/training/diagnostics`：状态、报告、解释与统计；可用report参数固定版本。
- GET `/api/training/diagnostics/cases`：类别、模型、台站、错误、样本ID、排序与分页，默认24/页。
- GET `/api/training/diagnostics/assets`：仅报告登记的内部PNG资源ID及固定报告文件名，拒绝任意路径。

主要产物：`identity.json`、`source/`、`audit.json`、`samples.json`、`cases/`、`probabilities/`、`models/`、`case-index.json`、`report.json/md`、`interpretation.json/md`、`station-intervals.json`、`next-experiment-proposal.json`。

为避免复制多份概率图占用空间，后续诊断版本对已完成的逐图缓存使用同卷硬链接，先校验后复用；任何重写均以新文件原子替换，旧版本内容不会被原地修改。
