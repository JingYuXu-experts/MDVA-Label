# 训练前准备：Conda 环境与数据验收

日期：2026-11-12。执行范围是训练前的环境、数据关联、划分和读取检查；没有开始正式模型训练，也没有把随机初始化的试运行称为太阳识别效果。

## 现在使用哪个环境

模型使用已有的 **`mdva311`**，解释器在 `E:\ANACONDA\envs\mdva311\python.exe`。原来的 **`mdva`** 保留给现有网页服务，包版本与准备前逐项比较一致。没有向 Conda base、系统 Python 或 C 盘的 Python 环境安装包。

`mdva311` 已安装项目、图像/表格/科学数据依赖，以及 PyTorch、Torchvision、Scikit-learn、Albumentations、Hydra、Safetensors 等模型准备依赖。PyTorch 使用官方 CUDA 12.8 发行包：`torch 2.10.0+cu128`、`torchvision 0.25.0+cu128`。使用现有显卡驱动，没有重装系统 CUDA 或驱动。

安装期间实际发现 NumPy 2.4 与 Astropy 6 的运行时冲突，已固定为 NumPy 2.2.6。`pip check` 不会发现这类问题，因此验收还包含实际库导入和 GPU 运算。

安装包、pip 下载缓存、模型缓存、编译缓存、Matplotlib 配置和临时文件都设置在 `mdva311` 环境下，相关变量由 Conda 随激活自动设置；没有设置系统级 PATH。第三方模型源码也放在该环境的 `model_sources` 下。

### 使用方式

在 Anaconda Prompt 中执行：

```bat
conda activate mdva311
cd /d "F:\毕业设计多图像浏览器\MulimgViewer-master"
python -m mdva.training.environment_check
```

也可以双击项目根目录的 `打开模型环境.bat`，直接进入已激活的终端。该入口不自动开始训练。若当前终端已激活过旧配置，需要重新激活一次以加载本轮环境变量。

## 已验证的模型运行能力

- RTX 5060 被识别为 CUDA 设备，计算能力为 12.0，发行包含 `sm_120`。
- 真实 CUDA 卷积、混合精度、损失与梯度计算通过。
- Torchvision 的 CUDA NMS、注意力反向传播、ResNet34 前向通过。
- Flat U-Net 作者 32 通道架构的 512×512 前向与反向通过。
- SAM 2.1 Tiny 的 1024×1024 图像编码器前向通过。
- 数值特征缺失填补与缩放检查通过；所有要求的第三方库都从选定 Conda 环境读取，用户 site-packages 关闭。

这些是运行能力检查，没有训练分类器、更新网络权重或加载预训练权重。Flat U-Net 源码保留作者许可与来源哈希；SAM 2 固定官方提交 `2b90b9f5ceec907a1c18123530e92e794ad901a4`。SAM 安装采用官方允许的关闭可选 CUDA 扩展方式，核心推理使用 GPU；涉及该扩展的后处理功能应在正式接入时单独核验。

## 数据关联与划分处理

原始数据保持不变，准备结果写在：

`out/pretraining-20261112/dataset-ready/`

中间的 `dataset-v1` 仅保留核查证据，不能用于正式训练；它暴露了 CH/FL 的空验证集，已在最终协议中修正。最终读取器检查文件清单哈希；源文件第一次读取校验内容哈希，后续也检查大小和修改时间，发现变化即停止。

已完成以下处理：

1. 图像逐张实际解码，掩膜逐份读取取值、形状和分量；所有原始文件建立 SHA-256、大小及修改时间记录。
2. 使用完整的仪器文件名规则解析时间，覆盖 HMI/MDI 的 TAI→UTC、AIA、BBSO/KSO 和 HSOS 特殊命名，避免随意截取八位数字产生假日期。
3. 图像、掩膜、参数表和 NOAA 对应表按文件与实例关联。四位 NOAA 编号仅在同图同实例对应表能唯一核验时转换，原编号和转换依据保留；事件中的短编号使用邻近日期参考核验。
4. 参数表有记录但掩膜中没有实例、标签与事件重建不一致、关联不确定等情况进入隔离清单，不为凑齐样本猜配。
5. 耀斑开始时间与等级可核验但峰值/结束时间缺失时，可用于相应目标检查；缺失字段保留为空，不补造时间，也不进入需要完整事件的历史特征。
6. 无掩膜图像保持未标注，孤立掩膜不进入图像监督。AR 的非法负值掩膜及相关预测记录隔离，没有把非法像素擅自改成背景。
7. C/M/X 标签按实例核验一致性，M+ 标签与事件表按未来 24 小时窗口重建比较；缺少可靠归属的强事件会阻止相关不确定负例进入训练。
8. 原始耀斑指数 FI、NOAA 身份字段、未来标签和无法核验历史发布时间的 Hale/McIntosh 不进入首版预测输入。数值参数的缺失保留指示列，只在训练集拟合填补与缩放。
9. 相同观测、相同解码像素与同一 NOAA 区域检查跨划分泄漏，冲突隔离，不把未来样本移入训练集。

最终时间协议在任何模型训练开始之前按标签覆盖调整：

| 任务 | 训练 | 验证 | 校准/阈值开发 | 冻结测试 |
|---|---|---|---|---|
| AR 分割、活动区参数预测 | 截至 2020 年 | 2021 年 | 2022 年 | 2023 年至 2024 年 5 月 |
| CH、FL 独立分割 | 截至 2018 年 | 2019–2020 年 | 2021–2022 年中可用标注 | 2023 年至 2024 年 5 月 |

分割边界两侧采用 27 天保护区，当前日级数值预测采用 4 天保护区，并检查活动区重叠。不同任务独立训练，不共享拟合权重；未来若建设跨任务共享编码器或多模态融合，需重新统一数据协议。验证器现在会明确拒绝空划分，也拒绝预测划分没有正例或负例的情况。

原始 21,232 条参数记录中，**20,365 条**通过首版研究基线准入：

具体处理结果：

- 979 条参数表短 NOAA 编号已由同图同实例的对应表唯一核验，全部保留原值和依据。
- 553 条参数记录没有实际掩膜实例，不能构造区域监督；非法掩膜关联的 8 条记录另行隔离。
- 实际实例中的 M+ 标签与事件重建仅剩 1 条不一致，已隔离：`20220815` 的实例 3、NOAA 13079。原标签为 0、按事件表重建为 1，没有擅自覆盖原标签。
- 7 条重复事件去重后保留 23,559 条，1 条核心字段非法；14 条缺少完整峰值/结束顺序信息，不用于要求完整时间的历史输入。
- 未能可靠匹配归属的 M+ 事件会使相关负例受限；对应隔离 194 条记录。时间边界及跨划分活动区也按规则隔离。不同原因可能落在同一记录上，不能把原因计数直接相加。
- 9,718 组解码像素相同的图像已记录。最终可用集合的同源/活动区跨划分检查通过。

最终清单哈希、36 个真实图像—标签读取样例、10 列数值矩阵、训练集专属预处理均通过验证。`reference-alignment.png` 提供三类原始参考的对齐图；这只是叠加位置检查，不替代科学标签的专家复核。

再次核验已准备数据：

如原始数据将来改变，应写入新的输出目录重新准备，不能覆盖旧冻结记录：


## 复现与边界

环境证据位于 `out/pretraining-20261112/`，包括安装记录、包清单、Conda 显式包记录、GPU 检查和测试日志。`requirements/model-torch-py311.txt` 固定官方 GPU 包，`requirements/model-compatibility-py311.txt` 固定已确认的兼容约束，`requirements/verified-model-py311.txt` 记录其余已验证 Python 包。应用与官方 SAM 源码需分别安装，不把 PyPI 上的同名包当作官方来源。

本次准备的预测样本用于**回顾性研究的数值参数基线**。历史 SRS/事件的真实发布快照没有因此补齐，字段已按协议排除或标明研究状态；实时物理参数获取、模型训练、精度验证、概率校准和前端 AI 接入仍属后续阶段。当前监测网页继续运行，现有人工标注未被修改。

软件全量回归为 **723 通过、18 跳过、0 失败**；跳过项仍为需要显式开启窗口的旧桌面 GUI 用例。针对短编号、时间解析、空验证集、真实实例、未完成事件的未来信息隔离、训练集独立预处理、越界路径与清单篡改的准备测试也通过。GPU 检查的 PyTorch 分配峰值约 911.7 MiB，仅代表本次数值检查，不是正式训练显存估计。
