# 自动识别、自动标注与事件预测：目标接续

目标保持完整：输入适配的太阳观测图像，可靠稳定地自动输出对应现象范围和标注，并结合可获得的观测资料预测可能的空间天气事件。当前状态：进行中，尚未验收目标完成。

## 本轮实际改变

标注页任务完成后新增“下载整批自动标注”，无需逐图接纳或人工勾画。原尺寸二值掩膜、COCO RLE、可编辑多边形、区域位置/像素面积/重心以及数据与权重身份一起输出。机器结果与人工版本分开。

COCO RLE保留孔洞与退化的小区域。连通区域只表示像素连通性，不自动赋予物理实例身份。COCO的iscrowd=1用于未压缩RLE格式，不表示太阳结构成群。多边形转换失败有原因清单，完整栅格不丢弃。

真实验证：AR/CH各30张既有自动推理输出，通过Chromium下载，无需接纳到人工草稿。AR 126个连通区域；CH 110个连通区域，包括9个含孔洞区域。60张COCO RLE重建与模型掩膜逐像素一致。该核对证明导出完整，不证明模型预测正确。

证据：`out/acceptance/model-release-20261116/machine-products/browser.json`、`pixel-readback.json`、AR.zip与CH.zip。专项23项通过；前端lint、类型检查/构建通过。没有重训，也没有改变冻结模型、阈值或评价数据。

## 仍未完成的核心问题

- 自动结果的质量：现有独立测试暴露验证到测试的下降，不能把直接导出当作可靠性提升。
- 普通图片输入：当前只支持已登记并确认条件的HMI显示域磁图/AIA193 JPG或PNG；上传即分析的独立入口、未知仪器与不适配图像拒绝仍需完善。FL未达到交付标准。
- 事件预测：当前区域包不生成预测。既有预测研究使用MGB_PIL、R、MGB、Total_Unsigned_Flux、Area五个参数，其业务科学门槛仍未通过。当前灰度JPG不含经过标定的磁场数值，不能从分割像素面积冒充磁通量或物理面积。

## 下一步顺序与证据门槛

1. 用现有验证资料评估“大致范围定位”：定位召回、漏检、误检、框IoU及不同面积目标分层，与精细分割Dice分开。先检查现有推理，不能围绕已打开的测试集调参。没有可靠无目标负例时，独立误报率仍保持未知。
2. 对严重错误复核实际输入与参考；区分通道不适配、标签语义、图像缩放、台站/时间差异。每个新增训练实验必须有能被否证的假设、内部开发划分及资源预算；不重新盲跑原矩阵。
3. 完善输入即分析产品入口：图像登记、观测条件确认、自动运行、自动产物、失败重试与任务恢复；人工编辑是可选操作，不作为产出机器标注的前提。
4. 预测先审计输入链路与监督：已编号活动区未来24小时M+耀斑作为已有研究任务；需要核验物理磁图、区域关联、特征在T时刻的可获得性、权威事件覆盖。CH到高速太阳风、CME到地球影响分别需要其他观测与独立传播依据，不合并为一个不明含义的“太阳风暴概率”。
5. 形成冻结外部评价和实际产品验收。目标完成须有真实输入下的自动产物、质量与失败边界、稳定运行，以及可核验的事件预测评价；仅测试通过、训练完成或页面能显示不算完成。
