### 关机暂停与恢复

暂停写入`scss-full-01/run/PAUSE`，等本轮保存并确认训练进程退出。用户明确恢复后，先保留并撤销用户暂停标记，核验身份，再执行：

```bat
python -m mdva.training.scss_resume --study out/recognition-improvement-20261117/scss-full-01
```

该入口按实际检查点计算距离20轮还剩多少轮，例如从15轮恢复只运行剩余5轮，避免每次恢复又追加完整12轮。运行中不要重复启动。原始数学代码和既有检查点身份保持不变；阶段预算展示通过独立元数据修正。

## 多通道输入的可行性补充

官方公开的历史AIA synoptic FITS支持按原图名义时刻取得193/211通道。已核验固定首张训练图2010-05-13 15:00：两通道T_OBS相差6秒，质量字段均为0，1024网格、相应WCS网格字段一致。原始HDU的一补校验和及DATASUM通过；无需修改原文件来绕过非标准nan头卡。

按数据团队提供脚本的固定公式重建193显示图，固定中心180像素半径范围内，与本地训练JPG相关系数约0.99584、平均绝对差约1.33/255；未拟合强度或几何参数。但本地JPG的日面外白背景处理仍未由该脚本解释，完整像素对应尚未验收，不能立刻拼接多通道训练。

这一结果支持继续核验同源观测，不说明用户原数据下载不完整，也不证明全部训练图都有同样映射。该历史产品从最终Level1加工，约7天后产生，不能当作当时即可获得的实时预测输入；NRT产品的约15—20分钟延迟、缺口和乱序需要另行处理。[官方产品说明](https://jsoc1.stanford.edu/data/aia/synoptic/README.html)

核验证据位于`out/solar-observation-audit-20261117/exact-time-01/mapping-review.json`。其中`multichannel_training_allowed=false`明确保留，尚无新多通道训练。
