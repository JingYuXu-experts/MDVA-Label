# 三维日地视景实现与验收

> 历史记录：本页球冠/粒子传播表现已按用户的物理真实性要求停用，旧视频不能作为真实传播依据。当前状态以[物理审计](三维物理审计与教学说明-20261111.md)为准。

日期：2026-11-11。根据用户本轮要求，新增交互三维视景，保留先前官方二维模型。此前“第一轮仅二维”的安排按本次要求调整；未增加自主磁流体数值求解器。

## 入口

刷新 http://127.0.0.1:8765/monitor 。日地传播区域默认“三维日地场景”，点击“进入三维全屏”进入独立视景。右侧切换日地全景、地球近景、太阳近景、黄道俯视；左键环绕、滚轮缩放、右键平移；Esc退出。无全屏权限时仍可使用铺满视口的剧场模式。

“官方二维模型”保留原WSA–ENLIL图片、批次、逐帧播放、原始色标及对照。两个视图明确分开署名。

## 已实现

- 真正的Three.js WebGL场景、OrbitControls、摄影机平滑过渡、Bloom辉光、细分球面、自定义太阳/地球/大气/日冕着色器。
- 地球昼夜面、静态夜景、独立云层、海面镜面反射、大气边缘；太阳静态材质、颗粒层次、日冕与示意弧线。
- Astronomy Engine按场景时间计算地球J2000黄道位置；轨道参照与AU标记。默认天体半径放大便于观察，可切换真实尺寸比例。地球轴向/自转为视景近似，非精密姿态服务。
- 根据DONKI CME的速度、经度、纬度、半角绘制可旋转观察的传播薄壳、体积层次和粒子材质。缺少任一必要参数时不绘制传播体，保留缺失提示。
- 事件选择、0—120小时回放、倍速、暂停、空间距离提示；传播半径按速度×经过时间计算，不输出由此推导的到达预报。超过1.5AU时不冻结在地球位置。
- 日地参考角度采用近似投影。它不是ENLIL体数据重建；颜色、粒子与内部纹理不是密度观测。依据面板与页脚始终区分位置计算、事件示意和静态材质。
- 高画质/均衡画质；渲染上限60/30帧；隐藏标签页停止绘制，切换视图销毁摄影机控制、监听、缓冲、纹理和后处理资源。
- WebGL无法创建时显示中文错误，仍可切换二维模型；手机布局与触摸控制。
- 材质和代码随本地构建打包，加载三维不依赖外部CDN。纹理来源与许可见 frontend/src/assets/space/README.md。

## 边界

该版本提供专业三维渲染与参数化事件表达。后续若要声称重建真实三维等离子体密度、速度或磁场，需要取得完整模型网格、坐标、时间和单位数据，增加体渲染与独立科学验证。当前官方二维结果继续用于核对原模型。

未修改原始数据或人工标注，未推送GitHub。太阳识别与耀斑预测模型的训练状态不因三维界面变化而改变。
