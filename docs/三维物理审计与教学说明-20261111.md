## 已纠正的表现

原视频中的球冠、圆盘状薄壳、规则环纹和粒子阵列是图形近似，未经过CME形态或三维传播验证。它们不能作为真实太阳风暴形态、准确传播轨迹或冲击波证据，现已从运行场景停用。原方向代码也不再用于绘制传播体。

仅有DONKI的速度、经纬度和半角，不能唯一重建真实CME的形状、内部密度、磁场、加速度和冲击过程。HEEQ坐标与黄道、日心、地心参考系不能混用。该限制直接显示在“CME”“冲击波”的讲解中。

太阳在此日心参考系中位于原点。地球围绕太阳公转；没有让太阳围绕地球转。太阳绕银河系的运动不纳入日地空间视景。

### 磁场的范围与强度

目前绘制1—3个参考地球半径，`Rₑ=6371.2 km`。这是绘制与模型展示范围，不是磁场到3Rₑ就消失，也不是“保护罩边界”。磁力线遵循中心偶极分量的 `r=L sin²θ` 关系并按地理磁偶极方向旋转。悬停可查距地心半径和模型强度nT。

磁场的日侧压缩、长磁尾以及弓激波需要外部场和太阳风耦合模型。不能用一个偶极线圈或一个L1动压值替代真实磁层。

## 连续运动与教学交互

- 太阳自转、地球自转与公转共用同一个时间，不用三个互不相干的装饰速度。
- 背景默认教学加速3600倍，提供1×实时、1小时/秒、1天/秒、3天/秒。页面明确显示场景时间和倍率；加速未来场景不是预报。
- 可暂停运动、返回当前时间。事件查阅按选中事件时间回放；暂停时间也会暂停相应物理运动。
- 地球和近地磁场摄影机跟踪目标位置，防止公转后飞出近景。
- 太阳、地球、磁力线支持鼠标悬停和点击；底部还提供太阳、地球、磁场、太阳风、CME、冲击波的讲解按钮，支持键盘与手机点击。
- 每张讲解卡分别显示“是什么”“当前显示的情况”“模型边界”“依据来源”，可固定阅读和关闭。
- 当前L1监测时间与场景时间分开，不把当前观测移用成加速未来的实测状态。采样缺失、过期或不匹配时不计算正常结论。

## 后续真实传播/磁层所需条件

1. 接入具体物理模型的三维网格与时间序列，包含坐标、单位、密度、速度、磁场和边界条件；保留模型名、运行编号与有效时刻。
2. 数值场的插值、矢量变换、粒子示踪与磁力线追踪需独立验证。磁力线不等于粒子轨迹，显示用粒子数量也不能冒充真实粒子数。
3. 区分CME物质、CME驱动的行星际冲击波和地球附近弓激波。激波位置需要相应模型判据或观测，不由动画进度触发。
4. 可评估CCMC已有ENLIL、OSPREI及磁层模型产品；若输入/输出不齐，应保留不可用状态。不能仅为让画面丰富而生成相似形状。

“绝对真实”不能作为无误差保证。本平台按可核验模型、适用范围、数值测试和来源追溯验收；不将视觉逼真当成科学验证。
