# 太阳结构识别与对象整理研究方案

日期：2026-11-08。性质：基于文献的可检验研究方案，不是已取得的实验结论，不保证创新性或论文录用。

## 研究范围

目标是“多源观测 → 太阳结构识别 → 对象整理 → 人工核查 → 可追溯标注与对象档案”。排除耀斑概率预测、未来事件预测和整个 FPNet 的重建。现有耀斑数据可保留为原始资料，但不进入本轮模型输入、目标函数与验收。

不预先指定 U-Net、Mask R-CNN 或 SAM 为最终模型。先核验论文、作者实现、权重、输入预处理和数据划分；原代码不可得时，只能明确称为“按论文描述重建的基线”，不能称完整复现 SPNet。

## 文献依据与问题定位

原团队的 [Solar Activity AI Forecaster](https://arxiv.org/html/2508.06892v1) 中，SPNet 识别太阳结构区域，IATools 用 AR 的 DBSCAN、CH/FL 的连通域与邻近合并等形成对象，再进行编号、跟踪及分析。原文图 6 明确记录相邻活动区被错误合并，说明像素识别与对象组织是两种不同正确性。该工作已有多模态与人工反馈迭代，不能把这些概念本身当作我们的新贡献。

近邻研究已包含 [HARDAT/HDBSCAN 活动区检测与跟踪](https://arxiv.org/abs/2605.23150)，因此“DBSCAN 换 HDBSCAN”不是可直接宣称的新方法。[Topology-Aware Uncertainty for Image Segmentation](https://proceedings.neurips.cc/paper_files/paper/2023/hash/19ded4cfc36a7feb7fce975393d378fd-Abstract.html) 已研究结构级不确定性与专家核查，相关机制应作为对照和参考，不能改名声称原创。后续仍需补充完整近邻文献检索。

## 建议主问题

**在固定识别器与固定人工审核预算下，能否减少太阳结构的错误合并/拆分，并降低获得同等标注质量的人工成本？**

首个重点建议放在 AR，因为现有数据有实例编号与 NOAA 关联，可建立明确的对象评价。CH/FL 继续保留区域识别，但其现有二值标签不足以直接验证对象归属；若扩展对象实验，需另建经核查的对象级标签。

## 待验证方法

1. 保留经过核验的识别器输出，先不更换主干网络，以隔离对象整理的贡献。
2. 将候选区域片段及其邻接关系组成对象关系图。检查日面半径归一化的距离、形状、边界/间隙证据及可用的观测特征，判断合并或分离，而不只使用一个固定距离阈值。
3. 为对象关系提供可核验的风险指标：例如在阈值或输入扰动下，区域是否反复合并/拆开。若有模型概率，再评估关系分数校准。简单基线和复杂方法采用相同输入条件。
4. 稳定且明确的候选进入普通审核；高风险合并/拆分优先交给人工。用户执行合并、拆分、边界修订或“无法确定”，记录实际耗时与理由。
5. 只用训练/验证反馈更新方法；测试集不进入再训练。更正前后结果与来源均保留。

以上是拟验证的方法结构，不是已经实现、已优于前人或已确认创新的算法。若数据证明更简单的方法效果相当，应保留简单方法，不堆叠模块。

## 基线与实验设计

### 对象整理实验

- 固定同一批输入掩膜，比较连通域、调参后的 DBSCAN、可复现的层次密度方法，以及待验证的关系整理方法。各方法均在验证集调参，不能只比较未调参的弱基线。
- 对可用的原团队规则进行按文献重建，并公开缺失参数与假设。作者未公开的实现不得伪称已复现。
- 可将 AR 参考实例合并成二值前景，测试对象整理能否恢复实例关系；必须标为“真值前景输入的模块诊断”，不能当成端到端识别性能。
- 另用同一个实际识别器的预测掩膜做端到端评价，检查像素错误与整理错误如何叠加。
- NOAA/参考实例标签用于测试关联正确性，不向自动分组器提供测试真值身份；既有标注对象的物理参数也不作为隐蔽的真值提示。

### 人工标注效率实验

比较纯人工、按日期顺序修订、像素不确定性排序、对象关系风险排序。控制同样审核时间/操作预算与起始标签量。记录达到同等质量所需时间、修订次数，以及单位时间修复的严重错误数。不同流程使用平衡顺序或交叉设计，降低先看过图像产生的记忆偏差。

### 数据与真值

- 按日期块划分，并检查相同活动区、近重复、跨波段同源及派生数据泄漏；训练、验证、测试各自用途固定。
- 先建立少量有代表性的疑难对象集，覆盖近邻活动区、弱小区域、太阳边缘、多分量和跨仪器情况，再决定正式样本量。
- 原始标签不视为无误真理；对疑似漏标、归属歧义保留原标注，独立核查并记录裁决。没有合格专家参与时，结论应限于参考标注一致性，不能宣传专家级科学准确性。
- CH/FL 若无对象级核查标签，仅报告区域分割指标和定性案例，不计算虚假的实例真值指标。

### 指标与消融

- 区域：IoU、Dice、边界质量、空图误报。
- 对象：一对一匹配后的召回/精确率、误合并率、误拆分率、计数误差；可补充适用的实例掩膜指标。
- 人工：同质量所需时间、固定预算后的对象质量、严重错误修复数。
- 稳健性：按年份、仪器、台站、日面位置分层；统计区间按日期或活动区重采样，不能把强相关像素当独立样本。
- 消融：基础规则、加入自适应关系、加入风险估计、加入人工反馈逐步比较。保持识别器、数据量与审核预算一致。

## 平台角色与论文边界

平台负责同日多波段对照、原始参考/模型候选切换、对象合并拆分、来源与版本、审核队列及实验记录。它是方法运行和证据收集的载体。

更好看、按钮更多、换一种模型或简单拼接现成模块，不足以证明研究创新。拟定贡献必须是对象组织或标注效率上可复现的改善；不要求在所有指标上超过整个原预报系统，也不声称我们研究了被排除的预测任务。

暂定选题表述：**面向太阳结构识别的不确定性感知对象整理与交互标注方法**。是否形成论文主贡献，在复现、近邻文献核查与预实验后决定。若预实验不支持优势，应缩小或调整问题，不提前写优于现有方法的结论。

## 下一步顺序

核验可复现基线 → 建立 AR 对象疑难集 → 固定掩膜比较整理规则 → 验证人工审核收益 → 扩展 CH/FL → 端到端识别验证与平台整合。模型安装和正式训练须有明确的复现目标，不继续按旧架构候选盲目推进。
