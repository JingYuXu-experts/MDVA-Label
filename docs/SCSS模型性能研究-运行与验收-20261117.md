## 第8轮必须做的评价

训练在完整轮边界停止后，先核验进程退出和GPU锁释放，再执行：

```bat
python -m mdva.training.scss_review --study out/recognition-improvement-20261117/scss-full-01 --output out/recognition-improvement-20261117/scss-review-08
```

该独立评价命令已实现，尚未在新模型上运行。它会：

1. 只接受完整第8轮、停止状态及匹配身份，拒绝抢占仍运行的训练。
2. 固定选择首8轮中的最佳验证检查点，复算完整526图。Dice与保存结果的差异超过1e-5时停止结论。
3. 使用同一图像的原C2缓存，验证掩膜哈希及TP/FP/FN回读一致性；模型前向之后才读取参考。
4. 输出逐图Dice、IoU、Precision、Recall、边界F1、原生预测和概率缓存，允许按身份恢复。
5. 评价8连通参考区域的完全漏分、至少一半覆盖、区域框匹配及额外区域；连通区域不等于物理实例。
6. 分2019/2020年展示结果，并输出UTC27日时间块配对bootstrap区间，避免只看总平均。
7. 将继续开发门槛和产品实用门槛分别报告。当前没有独立空参考样本，不能报告无目标图像误报率。

训练只读原始数据，派生成果独立保存。复算不会修改原始掩膜、现有模型包或已完成的原测试记录。

## 门槛和后续

首8轮继续门槛严格沿用训练前协议：第8轮Dice≥75%且后4轮均值比前4轮高至少2个百分点，或第8轮Dice≥79%。不根据前几轮的好坏临时修改门槛。

实用性门槛是验证Dice至少82.07%、Precision至少83.17%、参考区域至少半覆盖比例至少70.88%。这是工程筛选，不等于统计显著、独立测试通过或模型允许发布。通过继续门槛时，仍要检查精度—召回取舍和错误分层，再决定有限后续预算；失败时不自动跑满40轮。

正式采用之前还需要收敛后的固定配置、其他随机种子、错误案例、资源及真实输入验收，并解决独立评价与人工复核要求。FL及事件预测继续保留未完成状态。
