# 三维日地场景：四步讲解与验收

> 后续界面已按用户意见调整：默认简洁浏览，四步教学从“图解说明”打开；影响摘要在顶部，分析资料默认折叠。以下保留本轮功能与原验收记录；当前布局以[影响优先与收纳验收](三维日地界面-影响优先与收纳验收-20261112.md)为准。

## 用户应该从这里得到什么

先理解太阳、太阳风和地球磁场之间的空间关系，再查看某一次真实喷发是否有来源给出的地球到达估计。空间理解和事件判断分别展示，不能凭磁力线、动画进度或箭头位置宣布太阳风暴到达。

原版默认同时显示轨道、全局场线、来流和大量专业参数，缺少看图顺序。现默认“入门讲解”，专业能力仍在“专业浏览”。

1. **认位置**：只显示太阳和地球，隐藏轨道、来流和场线，强调尺寸为增强显示。太阳与地球标注直接附着在对象附近。
2. **看太阳风**：出现较少的全向参考箭头，解释持续外流；新鲜L1数值可用时显示速度与质子密度，缺测或过期不填正常值。箭头数量不等于密度。
3. **看地球磁场**：镜头靠近地球，标注迎日侧、磁尾侧；亮场线和淡边界分别说明。进入这一步才初始化全局模型。模型未取得时只解释实际显示的内源场，可直接重试；更新失败保留旧快照并明确提示，不冒充新结果。也可进入官方磁层变化回放。
4. **查喷发影响**：选择按北京时间命名的真实喷发，查看来源拟合方向、资料完整性和地球到达信息。此时才展开影响信息卡；来源未给出概率或到达时间时继续明确未知。

每步都有“看哪里、当前表示什么、下一步”。可直接跳步骤，也可重新对准画面。选择一次喷发后回到前三步会清除事件选择并返回当前天文时间，避免背景讲解混入历史事件。

## 保留的科学边界

- 太阳表面是实际观测可见半球的投影；灰蓝网格表示未观测一面。调亮未知区域的中性网格，使球体不会在黑背景中看似少了一半，不填充虚构背面活动。
- 天体位置来自天文计算。入门视角按屏幕比例取景，手机上也能同时找到太阳和地球；没有改变轨道与物理速度。
- 金色箭头是径向方向参考。白色场线和淡边界是模型快照，不能叫实拍或CME碰撞录像。
- 专业模式原参数、自由镜头、时间倍率、教学悬停和资料依据继续保留。原“播放事件”改为“推进时间轴”，明确只改变查看时刻，没有真实三维冲击过程可播放。
- 全屏入门前三步不摆放无关事件面板，太阳观测和磁层回放也不占用事件侧栏；第四步和专业场景展开对应信息。

科学说明参考[NOAA太阳风](https://www.spaceweather.gov/phenomena/solar-wind)、[NOAA地球磁层](https://www.spaceweather.gov/phenomena/earths-magnetosphere)。T96、IGRF及Shue模型数值实现未因本次讲解调整而更换；未增加三维MHD求解器或自主到达预测。
