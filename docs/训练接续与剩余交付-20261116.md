## 训练结束能带来什么

直接成果是可复核的AR/CH基线和主配置权重、三种子实验记录、验证结果、错误案例及资源实测。它们用于判断配方是否稳定有效、哪一套值得进入平台；不保证新种子的分数超过现有最好一次。

产品目标是：用户提供满足输入条件的磁图或AIA193图像，即使没有掩膜，也能得到AR或CH的像素区域候选，再由人审核修正并保存/导出。该用途必须经过后续独立评价和操作验收，训练完成不会自动变成已发布功能。FL现有低质量结果继续标研究状态。

实验可支撑论文中的同数据公平比较、种子波动、错误分析、精度—速度—显存取舍及负结果。已有结构、损失和增强须准确引用或说明适配，不能因训练了模型就声称原创或超过原团队大模型。

区域识别不等于耀斑定位、NOAA身份生成、CME到达时间或通信中断预测；这些能力不会随本批分割训练自动获得。

## 训练完成后的顺序

1. 汇总本批完整验证和错误分层，比较AR-A1/A0、CH-C2/C1的三个种子与资源表现，给出保留/研究/暂缓结论。
2. 固定准备部署的配置、阈值、预处理及输入范围，按修订子集生成可审计封存记录。独立测试确认后才运行一次，测试不回流调参。
3. 对通过质量检查的任务接入单图与批量候选，验证审核、修订保存、重启读取和导出；开展人工时间/质量比较。未通过的任务保持禁用发布。
4. 交付模型卡、论文表图、复现说明和演示。FL仅在错误原因及前置门槛解决后，另按原计划的最多4次候选预算推进；预测继续独立处理科学门槛。
