# 地图来源

`land-110m.json` 为 Natural Earth 1:110m land 数据，用于日照范围示意。

- 下载来源：https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson
- 使用条款：https://www.naturalearthdata.com/about/terms-of-use/
- Natural Earth 地图数据属于公有领域；本平台未包含第三方地图服务密钥或在线瓦片依赖。
- 日照范围采用太阳赤纬、均时差近似计算，不用于精密天文定位或通信链路故障判定。
